# 🫀 BioScan

### Biomedical Engineering Web Project

BioScan is a personal educational project created to explore the
connection between biomedical engineering, medical technology,
physiological data and software development.

## 🎯 Project Objective

The goal of BioScan is to demonstrate how a biomedical engineering
student can combine medical concepts with programming and digital
technologies.

## 🔬 Features

- Heart Rate Simulator
- Physiological data visualization
- Medical technology introduction
- Responsive web interface
- Interactive JavaScript components

## 🧠 Biomedical Concepts

The project introduces basic concepts related to:

- Heart rate
- Oxygen saturation (SpO₂)
- Body temperature
- Medical monitoring
- Biomedical devices
- Digital healthcare

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 🚀 Future Development

Future versions may include:

- Real sensor data
- Database integration
- IoT biomedical devices
- Interactive graphs
- Patient monitoring dashboard
- Data analysis

## ⚠️ Disclaimer

BioScan is an educational project.
The displayed physiological values are simulated and must not
be used for medical diagnosis or clinical decisions.
