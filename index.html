01 — ABOUT

What is BioScan?

BioScan is a personal educational project created to explore the connection between engineering, medical devices and healthcare. The project demonstrates how a biomedical engineer can combine programming, data and medical concepts.

🫀

Physiology

Exploring basic physiological parameters such as heart rate and their representation as data.

🩺

Medical Devices

Discovering the technology behind equipment used in modern healthcare.

💻

Programming

Using web technologies to create an interactive biomedical engineering demonstration.

02 — TECHNOLOGY

Inside BioScan

CSS
